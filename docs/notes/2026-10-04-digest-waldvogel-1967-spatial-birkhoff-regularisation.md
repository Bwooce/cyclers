## 0. What the paper is

Abstract (READ p.295, my translation): the work rests on an article by Kustaanheimo and Stiefel giving a map suited to the regularisation of three-dimensional Kepler motion. By composing that map with two inversions a map can be constructed that allows the simultaneous regularisation of the two singularities of the spatial restricted three-body problem and can therefore be regarded as the three-dimensional generalisation of the Birkhoff transformation. The associated differential-equation system is of ninth order; accepting a tenth integration, the same transformation also regularises the elliptic restricted three-body problem in space.
Scope: a method paper with no numerical example. The author says (p.330) that a programme in ALGOL was written from the formula collection of section 2.3 and run on a Control Data 1604 and that the experiments "met all expectations", but the results "will appear in a separate publication" (not held, not identified). So the paper prints no number usable as a published test; what it does print are exact structural identities (section 7). The three-dimensional Birkhoff map was first announced in Stiefel and Waldvogel, C. R. Acad. Sci. Paris 260:805 (1965) (reference [5], not held).
Why it matters here: the Stiefel and Scheifele book regularises one centre only (digest of 2026-10-04). Waldvogel's B3 map removes BOTH primary singularities of the restricted problem with ONE set of coordinates, in 3D, with an explicit formula collection meant for a program.

## 1. Chapter 1, the spatial Birkhoff transformation (pp.296 to 318)

### 1.1 The Kustaanheimo-Stiefel map (p.296 to 298, READ for (1) to (6); text layer for the rest)
x = KS(u) with x1 = u1^2 - u2^2 - u3^2 + u4^2, x2 = 2(u1 u2 - u3 u4), x3 = 2(u1 u3 + u2 u4) (1), r = |x| = u1^2 + u2^2 + u3^2 + u4^2 (3); polar forms (4) to (6): r = rho^2, theta = 2 alpha, psi = alpha + gamma. A one-parameter group of rotations V_phi of R4 (7), (8) leaves the image fixed (9), (10): the fibres are circles about the origin (this is the book's fibre, section 43 Theorem 1 of Stiefel and Scheifele, in an independent notation); only the origin and infinity have a single preimage. The Jacobian matrix K (11) (the KS matrix) is generalised orthogonal, K^T K = K K^T = N E (14), with norm N(K) = u1^2 + u2^2 + u3^2 + u4^2; the line element obeys dx1^2 + dx2^2 + dx3^2 = 4 (u1^2 + u2^2 + u3^2 + u4^2)(du1^2 + du2^2 + du3^2 + du4^2) (17) only if the differentials satisfy the non-holonomic side condition u4 du1 - u3 du2 + u2 du3 - u1 du4 = 0 (13) (the book's bilinear relation in differential form). Inverse map (18). The norm-product rule N(A1 A2) = N(A1) N(A2) (16) is used later.

### 1.2 Inversions (pp.298 to 300; text layer)
Liouville: in n >= 3 dimensions the conformal maps are generated by translations, rotations and reflections in spheres; only inversions (reflections in n-spheres, with a centre alpha and radius a, (19), (20), Jacobian matrix (26), norm N(A) = a^4/(sum)^2 (27), and the reciprocal-radii relation (21)) are used.

### 1.3 Derivation of the B3 transformation (pp.301 to 304; READ on images)
Key observation (p.301, READ): composing the inversion J0^3 (x -> x/|x|^2), the KS map and the inversion J0^4 of R4 gives back the KS map; so the KS map is conformal everywhere except at the origin of R4, and, by the two inversions, also "unconformal" at infinity. To get two finite unconformal points the author introduces a parameter space S4 and a physical space S3 and composes
 S4 --J4--> R4 --KS--> R3 --J3--> S3,  B3 = J3 o KS o J4,  y = B3(v) (38),
with the inversion J4 chosen so that the two unconformal points z1 = (-c, 0, 0, 0), z2 = (c, 0, 0, 0) (c > 0) (30) go to the origin and to infinity of R4, and J3 chosen so that the origin and infinity of R3 go to the two centres z1* = (c1, 0, 0), z2* = (c2, 0, 0), c2 - c1 = 2c (31). The inversion J4 in components (32) (the radius normalised by beta1 = 1):
 u1 = 1 + 2c (v1 - c)/[(v1 - c)^2 + v2^2 + v3^2 + v4^2], u_k = 2c v_k/[same denominator], k = 2, 3, 4,
with r_u^2 r_v^2 = 4c^2 (34), r_u^2 = (u1 - 1)^2 + u2^2 + u3^2 + u4^2, r_v^2 = (v1 - c)^2 + v2^2 + v3^2 + v4^2; J3 in (35), r_y^2 r_x^2 = 4c^2 (37). Substituting, the B3 map is, READ on p.303:
 y1 = (c1 + c2)/2 + (1/2)[ v1 + v1 (v4^2 + c^2)/(v1^2 + v2^2 + v3^2) ],
 y2 = (1/2)[ v2 + (v2 (v4^2 - c^2) - 2 c v3 v4)/(v1^2 + v2^2 + v3^2) ],
 y3 = (1/2)[ v3 + (v3 (v4^2 - c^2) + 2 c v2 v4)/(v1^2 + v2^2 + v3^2) ] (39).
It continues the planar Birkhoff map: in the v1, v2 plane, with v = v1 + i v2 and y = y1 + i y2, (39) reduces to y = (c1 + c2)/2 + (1/2)(v + c^2/v) (40), "exactly the conformal map known as the Birkhoff transformation" (p.304, READ).
Properties (p.304, READ unless stated):
- Many points of S4 have the same image (fibres); only the two centres z1, z2 have a single preimage.
- The whole v4-axis (v1 = v2 = v3 = 0) maps to infinity of S3: J4 sends it to the circle u1^2 + u4^2 = 1, u2 = u3 = 0, which KS sends to the point (1,0,0), which J3 sends to infinity. The v4-axis is therefore a "singularity in the parameter space".
- At the two centres the map behaves like KS at the origin: with relative coordinates (41) (v1 = sigma(vbar1 + c), y1 = sigma(ybar1 + c) + (c1 + c2)/2, sigma = +/-1) the expansions (42) start with ybar1 = (vbar1^2 - vbar2^2 - vbar3^2 + vbar4^2)/(2c) - ..., ybar2 = (vbar1 vbar2 - vbar3 vbar4)/c - ..., ybar3 = (vbar1 vbar3 + vbar2 vbar4)/c - ..., i.e. the second-degree terms agree with (1) up to a common factor, independent of sigma; at z1 with negative orientation (sigma = -1).
- Conformality (p.303, READ): the three-dimensional subspaces orthogonal to the fibres are mapped conformally, as for KS, except at the two unconformal points.

### 1.4 The inverse transformation, fibres (pp.305 to 310; READ for (45) to (49), (53) to (66))
Fibres in S4 are circles (or the v4-axis as the single straight-line fibre, or point fibres at z1, z2), the preimages of the KS circles under J4 (p.305). The automorphic transformations of S4 that map each fibre into itself are (READ p.306), for a fibre angle phi:
 (v1, v2, v3, v4) = (c/g) (2c v10, 2c(v20 cos phi + v30 sin phi), 2c(-v20 sin phi + v30 cos phi), 2c v40 cos phi + (v10^2 + v20^2 + v30^2 + v40^2 - c^2) sin phi) (45), g = (v10^2 + v20^2 + v30^2 + v40^2 + c^2) - (v10^2 + v20^2 + v30^2 + v40^2 - c^2) cos phi + 2c v40 sin phi (46),
g is never negative and vanishes only on the v4-axis. The distance from the v4-axis is d = (2c^2/g) sqrt(v10^2 + v20^2 + v30^2) (47); the points of a fibre with extremal distance lie in the hyperplane v4 = 0 (theorem, p.306); d_max d_min = c^2 (49, READ p.307); fibres lying entirely in v4 = 0 are those with v40 = 0, v10^2 + v20^2 + v30^2 = c^2, whose images are the points of the closed segment D* between the two centres (50), (51).
Back-transformation of a point y of S3 (READ pp.307 to 310): for y on D* (c1 <= y1 <= c2, y2 = y3 = 0) the fibre is v1 = y1 - (c1 + c2)/2, v2^2 + v3^2 = c^2 - v1^2, v4 = 0. Otherwise compute r1 = |y - z1*|, r2 = |y - z2*| (57), the auxiliary x = sqrt((r1 + r2)^2 - 4c^2)/(r1 + r2) (62) (real and positive off D*), then the outermost point of the fibre
 w1 = (y1 - (c1 + c2)/2)(1 + x), w2 = y2 (1 + 1/x), w3 = y3 (1 + 1/x) (64), rho = |w| = (1/2)[ r1 + r2 + sqrt((r1 + r2)^2 - 4c^2) ] (65),
and the whole fibre by the parametric form
 v(phi) = c/[(rho^2 + c^2) - (rho^2 - c^2) cos phi] (2c w1, 2c(w2 cos phi + w3 sin phi), 2c(-w2 sin phi + w3 cos phi), (rho^2 - c^2) sin phi) (66);
phi = pi gives the innermost point (c^2/rho^2)(w1, -w2, -w3, 0). The planar Birkhoff map of the (w1, W) plane gives (53) to (56). Useful identities (READ p.309): distances from the centres in the v variables (58):
 r1 = [(v1 + c)^2 + v2^2 + v3^2 + v4^2] / (2 sqrt(v1^2 + v2^2 + v3^2)), r2 = [(v1 - c)^2 + v2^2 + v3^2 + v4^2] / (2 sqrt(v1^2 + v2^2 + v3^2)),
and "the expressions in the v_k are distinguished from those in the y_i in that the partial derivatives of r1, r2 with respect to v_k remain continuous even when r1 or r2 vanish".

### 1.5 The differentials (pp.310 to 314; READ for (68), (75) to (89), (82))
B3 in the small: dy = B dv with B = 2 I3-tilde K I4 (72), generalised orthogonal, with the Jacobian b_ik = dy_i/dv_k. The fourth row of B is the side condition, which in the v variables is (READ p.312 to 313)
 a1 dv1 + a2 dv2 + a3 dv3 + a4 dv4 = 0, a1 = 2 v1 v4, a2 = 2(v2 v4 - c v3), a3 = 2(v3 v4 + c v2), a4 = c^2 - v1^2 - v2^2 - v3^2 + v4^2 (76), (81), (82a),
with b_4h = a_h/(2(v1^2 + v2^2 + v3^2)) (80). The 3 x 4 Jacobian rows b_1k, b_2k, b_3k are tabulated in (82) (p.313; for k = 1 the first row is b11 = [(v1^2 + v2^2 + v3^2)^2 + (v4^2 + c^2)(-v1^2 + v2^2 + v3^2)]/(2 (v1^2 + v2^2 + v3^2)^2), b12 = -2 v1 v2 (v4^2 + c^2)/(2(...)^2), b13 = -2 v1 v3 (v4^2 + c^2)/(2(...)^2), b14 = 2 v1 v4 (v1^2 + v2^2 + v3^2)/(2(...)^2), and similarly rows 2 and 3 with common denominators 2(v1^2 + v2^2 + v3^2)^2; the table is on the page image and the author notes that the entries are "by partial differentiation of (39)" so a program should differentiate (39) rather than transcribe the table; I did exactly that in section 8). Norm and metric (READ p.314):
 N(B) = r1 r2/(v1^2 + v2^2 + v3^2), B B^T = N(B) E (85), ds^2 = dy1^2 + dy2^2 + dy3^2 = [r1 r2/(v1^2 + v2^2 + v3^2)] (dv1^2 + dv2^2 + dv3^2 + dv4^2) (86),
boxed on the page, and the inverse dv_k = [(v1^2 + v2^2 + v3^2)/(r1 r2)] Sum_i b_ik dy_i (89). This is the analogue of the KS relation dx^2 = 4 |u|^2 du^2: the conformal factor is r1 r2/(v1^2 + v2^2 + v3^2), which vanishes at both primaries (it is the product of the two distances), and that is the origin of the time law of section 2.2.

### 1.6 Geometry (pp.315 to 318; text layer, with (100) on the text layer only)
The three-dimensional element spaces V3(v) (vectors dv satisfying the side condition) are mapped conformally onto the tangent spaces of S3; the kernel of the differential is the fibre tangent a(v). The side condition is non-holonomic: the planes of V3(v) cannot be integrated to hypersurfaces (they are "prickly" [stachlig]). Two-dimensional flat surfaces exist: the planes in v4 = 0 through the v1-axis. Every continuously differentiable curve C* of S3 that avoids the centres has a lift C in S4 whose tangents all satisfy the side condition (constructed with spatial elliptic coordinates, (95) to (102); the construction needs C* not to meet the y1-axis, which the later differential-equation treatment removes).

## 2. Chapter 2, regularisation of the restricted three-body problem (pp.319 to 330)

### 2.1 The restricted problem and the Lagrangian (pp.319 to 325; READ for (103) to (115), (125) to (131))
Setting (READ p.319): the massless body m moves under the Newtonian attraction of two central masses (1 - mu) and mu on circular orbits about their barycentre; units: total central mass 1, distance between the centres 1, time unit the reciprocal angular velocity; gravitational constant 1. Rotating coordinates y1, y2, y3 with the masses at (-mu, 0, 0) (mass 1 - mu) and (1 - mu, 0, 0) (mass mu): this is the project's `core/cr3bp.py` convention exactly. r1^2 = (y1 + mu)^2 + y2^2 + y3^2, r2^2 = (y1 + mu - 1)^2 + y2^2 + y3^2 (103), (1 - mu) r1^2 + mu r2^2 = y1^2 + y2^2 + y3^2 + mu (1 - mu) (104). Potential energy, with the free constant Phi0 = -mu (1 - mu)/2 (p.320, READ):
 Phi = -(1 - mu)(1/r1 + r1^2/2) - mu (1/r2 + r2^2/2) + y3^2/2 (106),
energy h = (1/2)(ydot1^2 + ydot2^2 + ydot3^2) + Phi (107), dh/dt = 0 (108) ("the right-hand side of (107) is sometimes called the Jacobi integral"), Lagrangian L = (1/2)(ydot1^2 + ydot2^2 + ydot3^2) - y2 ydot1 + y1 ydot2 - Phi (109). COMPUTED (algebra on (104) and (106), and numerically in section 8): h = -C/2 - mu (1 - mu)/2, C the project's `jacobi_constant` (x^2 + y^2 + 2(1-mu)/r1 + 2 mu/r2 - v^2); h is the PHYSICAL energy (sign opposite to the Stiefel and Scheifele h).
Regularisation scheme (pp.321 to 325). The B3 map is specialised to c1 = -mu, c2 = 1 - mu, so c = 1/2 and (c1 + c2)/2 = 1/2 - mu (111), giving (READ p.321)
 y1 = 1/2 - mu + (1/2)( v1 + v1 (v4^2 + 1/4)/(v1^2 + v2^2 + v3^2) ), y2 = (1/2)( v2 + (v2 (v4^2 - 1/4) - v3 v4)/(v1^2 + v2^2 + v3^2) ), y3 = (1/2)( v3 + (v3 (v4^2 - 1/4) + v2 v4)/(v1^2 + v2^2 + v3^2) ) (113),
with the side condition (114), (115). The Lagrangian in the four coordinates v_k is formed (119) and the Lagrange equations with a multiplier lambda(t) (116), a fifth unknown; multiplying the k-th equation by a_k and summing, using the orthogonality sum_k b_ik a_k = 0 (121), gives an equation (124) of the form (d/dt)(Sum_k a_k vdot_k times a non-zero factor) = lambda times a non-zero factor, hence lambda = 0 whenever the side condition holds (125) (the proviso: the v4-axis is never reached, and a collision r1 = 0 or r2 = 0 follows by continuity). The transformed equations (126), a system of order eight for v_k(t) (the multiplier drops out), and the initial values (127), (128): v_k(0) from the back-transformation of section 1.4 for any fibre angle, and
 vdot_k(0) = [(v1^2 + v2^2 + v3^2)/(r1 r2)] Sum_i b_ik ydot_i0 (128).
Under these initial values the side condition holds at all later times ("corresponding motion" in S4).

### 2.2 The time transformation and the regularised equations (pp.325 to 327; READ for (129) to (141))
Equation (130) is still singular at r1 = 0 or r2 = 0. Using the energy integral (131), h = (1/2)[r1 r2/(v1^2 + v2^2 + v3^2)](vdot1^2 + vdot2^2 + vdot3^2 + vdot4^2) + Phi (READ p.325), and a new independent variable (133), (134):
 s1 = integral of dt/(r1 r2), dt/ds1 = r1 r2,
the system becomes (READ p.326), with W-type function written out explicitly,
 d/ds1 [ (1/(v1^2 + v2^2 + v3^2)) dv_k/ds1 ] + 2 Sum_l (b_1l b_2k - b_2l b_1k) dv_l/ds1 + (v1^2 + v2^2 + v3^2) d/dv_k { [ -(1 - mu) r2 (1 + r1^3/2) - mu r1 (1 + r2^3/2) + r1 r2 (y3^2/2 - h) ] / (v1^2 + v2^2 + v3^2) } = 0, k = 1..4 (136),
in which y3, r1, r2, b_ik are the expressions (113), (58), (82) with c = 1/2. "One recognises that this system is no longer singular when r1 or r2 vanishes. With the system (136) the simultaneous regularisation of both collisions in the spatial restricted three-body problem is achieved" (p.326). The system is singular on the v4-axis, which is harmless because those points are the preimages of infinity and are never reached in finite time (p.326; the same happens for the origin in the planar Birkhoff regularisation).
A second time law (138), (139), READ p.327: ds = [(v1^2 + v2^2 + v3^2)/(r1 r2)] dt, i.e. dt/ds = r1 r2/(v1^2 + v2^2 + v3^2), has the same regularising properties and gives the simpler system (READ p.327)

### 2.4 Numerical remarks (pp.330 to 332; text layer except (144) to (147), READ p.331)
- "Nine integrations (eight for (136) or (140) and one for the time), that is three more than for the unregularised problem" (p.330). Advantages: besides the energy integral also the side condition (82a) is a free accuracy check; and "arbitrary orbits running in the finite part of the physical space can be computed without special measures: an accidental collision with a central body does not disturb the calculation at all". The most striking effect is an automatic adaptation of the time step at constant step length in s1 or s, since dt = r1 r2 ds1 or dt = r1 r2 ds/(v1^2 + v2^2 + v3^2) (143) shrinks strongly whenever the body approaches either centre.
- Warning on the s time law: the denominator v1^2 + v2^2 + v3^2 changes the time step unpredictably and makes it very large when the point v is near the innermost point of its fibre (close to the v4-axis); a method is needed "to avoid a strong approach of the orbit curve in S4 to the v4-axis".
- The remedy (READ p.331): the orbit in S4 may be modified by an automorphic transformation without changing its image. For c = 1/2 and phi = pi, from (45) one gets the special transformation
 v1* = v1/(4 |v|^2), v_k* = -v_k/(4 |v|^2), k = 2, 3, 4, |v|^2 = v1^2 + v2^2 + v3^2 + v4^2 (144),
with the derivatives transformed by the matrix (145) ((1/4) times a matrix with diagonal -v1^2 + v2^2 + v3^2 + v4^2, -v1^2 + v2^2 - v3^2 - v4^2, ... and off-diagonals +/-2 v_i v_k, as printed on the image). Criterion (146), (147): sqrt(v1*^2 + v2*^2 + v3*^2) = sqrt(v1^2 + v2^2 + v3^2)/(4 |v|^2), so the transformation increases the distance from the v4-axis exactly when v1^2 + v2^2 + v3^2 + v4^2 < 1/4; apply it after any step in which (147) holds; afterwards |v*|^2 > 1/4 (so it is not repeated). In the planar case this is the inversion to the inverse point in the v1, v2 plane.
- The v4-axis behaviour makes one wish for a regularisation that sends no finite point of S4 to infinity; for the planar problem Thiele's transformation does this; "it is not known whether it can be generalised to three-dimensional problems; transcendental functions would have to be introduced, leading to rather involved differential equations" (p.331, READ).

### 2.5 Collision orbits (pp.331 to 334; READ for (148) to (155))
A solution curve of (136) or (140) through an unconformal point (sigma/2, 0, 0, 0), sigma = +/-1, is a collision (ejection) orbit: the body collides in S3 with the centre at (1 + sigma)/2 - mu (mass mu for sigma = +1). Energy equation in s1 (READ p.332):
 (1/2)(v1'^2 + v2'^2 + v3'^2 + v4'^2) = (v1^2 + v2^2 + v3^2) { (1 - mu) r2 (1 + r1^3/2) + mu r1 (1 + r2^3/2) + r1 r2 (h - y3^2/2) } (148),
and at a collision with the mass mu the limits v1 -> 1/2, v2, v3, v4 -> 0, r1 -> 1, r2 -> 0 give
 v1'^2 + v2'^2 + v3'^2 + v4'^2 -> mu/2 (150) (collision with mu), -> (1 - mu)/2 (151) (collision with 1 - mu),
independent of h. To start a solution inside a collision one therefore chooses the velocity v' on the sphere (150) or (151); h can no longer be computed from the initial data (148) and is prescribed instead, replacing the degree of freedom lost by (150), (151). The solution then exists and is regular near s1 = 0; whether it continues analytically for all time is not studied (it would need Sundman's and Siegel's methods). The physical impact direction is the direction of (sigma ybar1, ybar2, ybar3), with ybar the KS image (154) of the regularised velocity (v1' sigma, v2', v3', v4') (152) to (155); conversely a prescribed impact direction (sigma ybar1, ybar2, ybar3) (156) gives the regularised initial velocity through the inverse KS formulas (157), (158), (159) (formulas on the text layer only). "Unlike the regularised velocity the physical velocity at a collision is infinite." The side condition is empty at the unconformal points. The ambiguity in transferring initial values into S4 comes, in this special case, from the velocity direction rather than the position.

## 3. Chapter 3, related problems (pp.334 to 340)

### 3.1 The elliptic restricted problem in space (pp.334 to 339; READ for (160) to (166), (173) to (182))
The central masses move on Kepler ellipses about their barycentre, with eccentricity e and parameter p = 1 - e^2 (units: semi-major axis of the relative orbit, orbital period 2 pi); true anomaly psi, separation l(psi) = p/(1 + e cos psi), angular velocity omega = dpsi/dt = sqrt(p)/l^2 (160); time by Kepler's equation (161). In the nonuniformly rotating, pulsating frame the equations (162); with the dimensionless coordinates y_i = eta_i/l (163), r_i = rho_i/l, the independent variable the true anomaly psi (Scheibner's suggestion), the equations are (READ p.336)
 y1'' - 2 y2' = -(l/p) dU/dy1, y2'' + 2 y1' = -(l/p) dU/dy2, y3'' + y3 = -(l/p) dU/dy3 (165), U = -(1 - mu)(1/r1 + r1^2/2) - mu (1/r2 + r2^2/2) + U0, l/p = 1/(1 + e cos psi) (166),
primes d/dpsi. There is no Jacobi integral because l/p depends explicitly on psi; a work theorem (169) replaces it, with U0 fixed by U(r1(0), r2(0)) = 0 (171), (172). The same scheme gives the regular system (READ p.339)
 d^2 v_k/dtau^2 + 2 Sum_q (b_1q b_2k - b_2q b_1k) dv_q/dtau + d/dv_k { W(r1, r2)/(1 + e cos psi)/(v1^2 + v2^2 + v3^2) + r1 r2 (y3^2/2 - h)/(v1^2 + v2^2 + v3^2) } - theta d/dv_k ( r1 r2/(v1^2 + v2^2 + v3^2) ) = 0 (180),
with W = r1 r2 U = -(1 - mu) r2 (1 + r1^3/2) - mu r1 (1 + r2^3/2) + r1 r2 U0 (178) (finite at both collisions), the time law d psi/d tau = r1 r2/(v1^2 + v2^2 + v3^2) (177) and one more differential equation d theta/d tau = [W/(v1^2 + v2^2 + v3^2)] e sin psi/(1 + e cos psi)^2, theta(tau0) = 0 (181), which replaces the singular integral of the work theorem (the integral was split off by partial integration so that the remaining one is proper at all collisions, (175) to (179)). The elliptic problem therefore needs ten first-order integrations (v_k, dv_k/dtau, theta, psi); the physical time follows from Kepler's equation without integration. The limit relation at a collision is (182): Sum_q (dv_q/dtau)^2 -> 8 mu/(1 + e cos psi_s) (collision with mu), 8 (1 - mu)/(1 + e cos psi_s) (collision with 1 - mu), with psi_s the true anomaly at the collision (the factor 8 comes from the second time law). The planar elliptic problem had been regularised by Szebehely and Giacaglia (1964) but with an integro-differential system (p.339).
### 3.2 Outlook (p.340)
Hill's lunar problem has one singularity and can be done with KS alone; the two-centre problem (two fixed centres) is regularised at once by B3, but it is exactly integrable with elliptic functions, so the use is small; Vinti's intermediary orbit (an oblate planet as two fixed complex centres) might benefit in numerical stability: "still the subject of further investigation".

## 4. How B3 relates to KS, to the book and to Heggie

- Construction: B3 = (inversion) o KS o (inversion). The KS map is the special case with the second centre at infinity. Near each primary B3 is KS in relative coordinates (p.304, (42)), so everything the book proves for KS holds locally at either primary.
- State: one 4-vector v with one non-holonomic side condition (the KS bilinear relation transported by the inversions), versus Heggie's two enlarged KS 4-vectors with constraint sum q_i = 0 and a canonical extended phase space (Heggie digest). Waldvogel's system is a Lagrangian one with a vanishing multiplier, second order in v (8 states plus time), non-canonical in the form printed; no Hamiltonian version, no symplectic structure, no variational equations are given. The book's canonical KS (chapter X) is not used.
- Energy: h appears as a fixed constant in the equations (it is an integral of the CR3BP), not as a variable as in the book's section 19 forms; so the time-independent restricted problem has no energy-sign issue at all: the same equations hold for elliptic, parabolic and hyperbolic motion about either primary.
- The time law dt = r1 r2 ds1 (133), (134) is the product of the two distances (conformal factor of (86) divided by |v|-type factor), regular at both primaries (the book's Theorem 3: exponent 1 at each centre).

## 5. How it handles the massless body near either primary

Near either primary the conformal factor r1 r2/(v1^2 + v2^2 + v3^2) goes to zero linearly in the distance to that primary, so physical time slows exactly as in KS, and the equations (136) or (140) are regular at r1 = 0 and at r2 = 0 (READ p.326). Close passes of either body are integrated with the same equations and the same coordinates, with no switch and no choice of centre; collisions (ejection orbits) are in the phase space (section 2.5). Moving away from both bodies, the coordinates v tend to the v4-axis or its neighbourhood and the time step in s becomes erratic (the v4-axis is the image of infinity): the author's remedy is the occasional automorphic inversion (144) to (147). A pass at infinity-like distances (large |y|) is therefore the cost of the formulation; the project's moon-pass problems are confined to |y| of order 1 and do not meet this.

## 9. Should it replace or complement the one-centre KS recommendation for #928?

Recommendation (INFERRED from the paper and the COMPUTED checks): complement, not replace.
- What B3 adds: one coordinate system and one equation set regular at BOTH primaries, with no choice of centre, no centre switch and automatic step adaptation near either body; a free second accuracy monitor (the side condition); an extension to the elliptic restricted problem at the cost of two more integrations (relevant to `#895`). It is the right tool for trajectories that pass close to BOTH primaries, for continuation families through collision orbits at either primary, and for tulip-type or other families where the pass distance to the small primary and the large primary are both small.
- What it costs: eight second-order variables plus time, with the b_ik table or its symbolic derivative; a singular v4-axis that requires the (144) to (147) reset (in practice at most occasionally, only when the orbit leaves the neighbourhood of the primaries); no canonical structure, no published variational equations, so a transition matrix has to be derived from (140) by differentiation (heavier than for the one-centre KS form, whose Hamiltonian structure gives symplectic checks); the fixed-h formulation makes the transition matrix with respect to initial conditions include the dependence of h on the initial state through the equation parameter (treat h as a state with h' = 0). The one-centre KS form with Coriolis as a force has the identical advantage of constant h and no singular axis.
- Project cases:
  - Earth-Moon second-species chains with passes near the Moon only (`#899`, `#928`): the one-centre moon-centred KS code of the Stiefel and Scheifele digest section 16.1 is sufficient and simpler; B3 would add nothing except a second structure for cross-checking (the existing r1 r2 Sundman code already carries its time law).
  - `#896` orbit 12i (pass 8.7e-6 from the small primary in that paper's units): one-centre KS about the small primary is enough for the tolerance test; B3 is an independent cross-check structure only. If an orbit of that family also passes within a small distance of the large primary, B3 removes the need for a switch.
  - Uranian two-moon orbits: B3 does not apply directly. It regularises the two primaries of a restricted problem whose primaries orbit each other; two Uranian moons orbit Uranus, not each other, so the spacecraft passes moon A and then moon B, each with Uranus as the dominant attractor. The one-centre KS form is then used per moon (centre = the moon of the current pass, Uranus and the other moon as perturbation, the Stiefel and Scheifele recommendation to shift the centre), and the planet-moon two-primary B3 form could in principle be used only for passes near the planet itself, which does not occur for these orbits (INFERRED).
- Order of work: build the one-centre KS propagator and its transition matrix first (digest of Stiefel and Scheifele, section 16.1); keep B3 as a second implementation of the same CR3BP flow for passes close to both primaries and as an independent cross-check; the program of section 8 can seed that work.
