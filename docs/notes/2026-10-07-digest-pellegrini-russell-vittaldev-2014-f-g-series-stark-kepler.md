## 0. Verdict

**The F and G (Lagrange f, g) Taylor series extended to the Stark problem: r = F r0 + G v0 + H p, plus a
time series T, in any generalised Sundman variable dt = c r^alpha dtau. Exact recursions, coefficients
generated by Maple to order about 25. Fast for short and medium steps (10-40 per revolution); alpha = 1
(eccentric anomaly) is markedly the best. A local, step-limited method: not for long arcs.**
- **Recursion (eq. 24, image):** F_{n+1} = F_n' + c r^alpha G_n (-mu/r^3), G_{n+1} = G_n' + c r^alpha F_n,
  H_{n+1} = H_n' + c r^alpha G_n; T_{n+1} = T_n' (eq. 26); F0 = 1, G0 = H0 = 0, T1 = c r^alpha. Low orders
  (eqs 27-28, image): F1 = 0, G1 = s, H1 = 0, T1 = s; F2 = s^2(-mu/r^3), G2 = T2 = s' = alpha s^2 (r.v)/r^2,
  H2 = s^2, with s = c r^alpha. The derivative rules close on r, s, k1 = r.v, k2 = p.r, k3 = p.v, k4 = v.v
  (eqs 29-35). Velocity comes from the tau-derivative of the series divided by s (eq. 36).
- **The Modern Taylor Series (MTS, Leibniz-rule automatic Taylor arithmetic) gives identical coefficients**
  (PDF p.3, text layer). So the method can be coded numerically, with no symbolic files. MTS is slower than the Maple-
  generated F and G below order 20 and faster above (PDF p.17, image).
- **Results (mu = 1 throughout):**
  - Sundman study (sec. 4.3, text layer, unperturbed a = 1, e = 0.6, 50 steps per period from periapsis, orders 8 and 12):
    both Taylor methods show "a narrow, but real, dip" of local error at alpha = 1; otherwise alpha about 1.25
    is best for them; RKF8 prefers alpha between 3/2 and 2 (time-velocity form) (Figs 3-4).
  - Timing (sec. 4.4, nominal a = 1, e = 0.8, p = 1e-3 [1, 1, 1] LU/TU^2, tolerance 1e-12; image p.17): F and G
    "optimal efficiency for orders between 10 and 15"; speed-up over RKF8 "from 5x for e = 0 up to 60x for
    e = 0.95"; large perturbations reduce the gain.
  - Low-thrust example (sec. 4.5, text layer): LEO to e = 0.94 with tangential thrust p = (q/r)(1 + cos nu) v-hat,
    q = 1e-3, piecewise constant per segment, Delta tau = tau_p/SPR; speed-ups 4x-15x vs time-velocity RKF8
    (Fig. 7).
  - Conclusion (image p.21): "between 3 and 60 times faster than a conventional RKF8"; best at orders 10-15,
    "approximately 20-40 points per revolution".
- **Error estimates (eqs 39-43):** Hamiltonian drift (floor 1e-16), the last-term norms Delta R, Delta V,
  Delta T (no floor; usable for step or order control), and an overflow guard (ratio of the n-th term to the
  first non-zero term; threshold about 100).
- **One printed slip found (Table 1, alpha = 2, image PDF p.7):** the printed tau-period 2 pi/(n c sqrt(a(1 -
  e^2))) is right only for a = 1. A direct integration gives 2 pi/(c sqrt(mu a (1 - e^2))) (= 2 pi/h): at a = 2,
  e = 0.3 the printed form gives 13.173, the integral 4.6574 (`check_stark.out` sec. F). The alpha = 0, 1 and
  3/2 entries agree with the integral to 1e-11 at (a, e) = (1, 0.7), (2, 0.3), (1, 0). For alpha = 3/2 the
  argument of K is the modulus k = sqrt(2e/(1 + e)) (scipy `ellipk` takes m = k^2).
- **What it gives the project:** the best-fit method for short constant-thrust segments (the `#999` DSM or
  low-thrust leg case), a coefficient check set (eqs 27-28), the tau-period formulas for step sizing, and the
  error-estimate rules. See `stark-plan.md`.
- **Catalogue implication (PROPOSAL only):** none.

## 1. Content

- **Sec. 1 (PDF pp.2-4).** F and G history (Steffensen 1956, Rabe 1961, Sconzo et al. 1965, Bond 1966,
  Broucke 1971, Papadakos 1983); Stark applications; Sims-Flanagan as the cheap alternative; analytic Stark
  solutions (Kirchgraber, Rufer, Poleshchikov, Lantoine-Russell) are complex and need elliptic functions; Yam
  et al. 2010 used MTS with the classic Sundman transformation for low thrust.
- **Sec. 2 (PDF pp.4-8).** Generalised Sundman transformation dt = c r^alpha dtau (eq. 2); alpha = 1, 3/2, 2
  give eccentric, intermediate and true anomaly. History: Baumgarte 1972 (alpha = 1 reduces Lyapunov
  instability), Velez 1974, Feagin & Mikkilineni 1976, Nacozy 1976/1977, Merson 1973 (alpha = 3/2 best for
  J2). "Time-velocity" (eq. 7) vs "tau-velocity" (eq. 9) first-order forms; Taylor series are tau-velocity.
  Table 1 tau-periods (below). Fig. 1: node spacing for alpha = 0, 1, 1.5, 2 (a = 1, e = 0.7).
- **Sec. 3 (PDF pp.8-12).** Problem statement (eq. 13, r'' = -mu r/r^3 + p); third basis vector p (works
  when p lies in the r0-v0 plane too); series (eqs 15-19); recursion (eqs 20-28); intermediate variables
  (eqs 29-35); velocity (eq. 36); Algorithm 1. Coefficient files become hard to compile near order 25.
- **Sec. 4 (PDF pp.12-21).** Hardware (gfortran 4.7.0, Xeon W3550). MTS benchmark (sec. 4.1). Accuracy
  measures (sec. 4.2, eqs 38-43). Sundman study (sec. 4.3). Timings (sec. 4.4, Algorithm 2, Fig. 5). Low-thrust
  application (sec. 4.5, eq. 45, Algorithm 3, Figs 6-8). Truth: quad-precision RKF7(8), tol 1e-25.
- **Sec. 5.** Conclusions (above). They also built F and G series for the CR3BP and for a perturbation constant
  in a rotating frame, with smaller gains (PDF p.18).

## 3. Golden candidates (published values only)

- **G-P1 low-order coefficients:** eqs 27-28 (symbolic): a Taylor or MTS implementation must give F1 = 0,
  G1 = s, H1 = 0, T1 = s, F2 = -mu s^2/r^3, G2 = T2 = alpha s^2 (r.v)/r^2, H2 = s^2 for any state. Exact.
- **G-P2 tau-periods:** Table 1 rows alpha = 0, 1, 3/2 (and the corrected alpha = 2) against a direct
  integration.
- **G-P3 published test definitions (no published end states):** sec. 4.3 orbit (a = 1, e = 0.6, 50 steps,
  orders 8, 12); sec. 4.4 nominal (a = 1, e = 0.8, p = 1e-3 [1, 1, 1], tol 1e-12); sec. 4.5 transfer (eq. 45,
  q = 1e-3, SPR 5-50). Truth must be our own integration.
- **Cross-implementation reference (not a published value):** the shipped `main_fg.f90` example (X0 =
  [0.2, 0, 0, 0, 3, 0, 0], p = [0.1, 0.1, 0.1], alpha = 2, c = 1, Delta tau = 0.6283185307179589, order 12) gives
  Xf = [0.19197735940685415, 0.076039918835258763, 3.2748052692689288e-5, -0.61096493394802398,
  2.8854997689473154, 2.5345371660955443e-3, 0.025676943776779589] (r, v, t) with |Delta H| = 5.9e-10. Our DOP853
  in the same tau agrees to 1.5e-13 in position and 2.2e-10 in velocity (series truncation;
  `check_fgcode_example.out`). The readme says the code changed after the paper's runs.
